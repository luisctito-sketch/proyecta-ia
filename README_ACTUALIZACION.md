# PROYECTA-IA · Actualización del portal principal

Esta actualización conserva el portal existente y realiza únicamente estos cambios:

1. Mantiene/añade el chatbot transversal **Viñetas, Conectores y Párrafos**.
2. Añade el chatbot transversal **Cartas Académicas**.
3. Incluye nuevamente la carpeta completa `defensa/` para que funcione la tarjeta **Presentación, Predefensa y Defensa Final** mediante el enlace `./defensa/`.

## Importante al actualizar GitHub

- Reemplace `index.html` por el incluido aquí.
- Suba la carpeta `defensa/` completa a la raíz del repositorio `proyecta-ia`.
- Conserve el `styles.css` y cualquier otro archivo ya existente en el repositorio. Esta actualización no modifica el diseño del portal.
- Puede volver a subir `portada_proyecta_ia_universal_v2.png`; es la misma portada utilizada por el portal.
