# PROYECTA-IA · Presentación y Defensa del Proyecto de Grado

Chatbot/web app educativo para preparar la predefensa o defensa final de un Proyecto de Grado.

## Ubicación dentro del portal principal

Este módulo está integrado en la carpeta:

`defensa/`

URL publicada:

`https://luisctito-sketch.github.io/proyecta-ia/defensa/`

## Archivos

- `index.html`
- `styles.css`
- `app.js`
- `README.md`
- `FUENTES_Y_CRITERIOS.md`

## Acceso centralizado por C.I.

El módulo usa:

`https://luisctito-sketch.github.io/proyecta-ia-acceso/access.js`

Por tanto, no se debe crear una lista local de C.I. en este repositorio. Las altas y bajas continúan administrándose desde el repositorio central de acceso.

## Publicación

Este módulo no necesita un repositorio GitHub Pages independiente. Los cinco archivos deben permanecer dentro de la carpeta `defensa/` del repositorio principal `proyecta-ia`. Al publicar o actualizar el portal principal, la defensa queda disponible automáticamente en `/proyecta-ia/defensa/`.

## Funciones principales

- Ruta recomendada de 30 minutos.
- Planificador de diapositivas y tiempo.
- Reglas de diseño visual.
- Revisor heurístico de una diapositiva.
- Revisión integral de una presentación completa: fondos, tipografías, ubicación, legibilidad, tiempos y coherencia.
- Generador de prompt para que el estudiante adjunte su PowerPoint/PDF/capturas en ChatGPT y reciba sugerencias de mejora.
- Enlace directo al video del docente sobre elaboración de diapositivas para defensa.
- Oratoria, postura y contacto visual.
- Manejo profesional del tribunal.
- Banco de preguntas de ensayo.
- Plan sugerido para los 10 minutos de prototipo.
- Cronómetro.
- Evaluación del tiempo de ensayo.
- Checklist persistente.
- Generador de ruta personal y prompt para simulación de tribunal con ChatGPT.
